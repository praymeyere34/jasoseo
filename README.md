# 이어쓰기

역량파악 검사 → 상위 성향과 역량 도출 → 성격 형성 및 역량 경험 분석 → 기본 이력 입력 → AI 자기소개서 작성 흐름을 가진 웹 앱입니다.

서비스: [https://jasoseo.site](https://jasoseo.site)

## 기능

- 휴대전화 문자 인증과 비밀번호로 가입 및 로그인
- 가입한 휴대전화 번호를 인증해 비밀번호 재설정
- 회원가입 시 개인정보 수집·이용 동의와 만 14세 이상 여부를 확인하고, 검사 전 민감정보 처리 동의를 별도로 받음. 동의 종류·버전·일시는 서버에 저장
- 개인정보 관리 화면에서 검사·경험·초안 삭제 및 민감정보 동의 철회, 비밀번호 확인 후 회원 탈퇴
- 사용 권한이 확인된 PAI 검사의 90문항을 바탕으로 상위 3개 성향과 역량 도출
- 90문항 모두 필수 응답. 유형별 1~9번 문항의 점수를 합산해 사용자에게 표시하며, 유형별 10번 문항은 점수에서 제외
- 검사 및 경험 기록 전에 목적, 활용 방법, 데이터 열람 범위를 설명
- 상위 역량별 형성 배경, 당시의 필요와 대응, 현재 반복 패턴 및 실제 경험과의 연결 근거 기록
- 자소서 근거가 될 상황, 행동, 결과 기록
- 거주지(동까지), 학교·전공·학적 상태, 알바·직장·인턴 이력을 선택 입력하고 계정별로 저장
- 회사, 직무, 문항을 입력해 Google Gemini API로 초안 생성
- 작성 중인 자료와 생성된 초안을 계정별로 저장하고 수정

## 실행

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_soft_carmella_unuscione.sql
npm run dev
```

AI 기능에는 서버 런타임에 별도로 등록한 Google Gemini API 키가 필요합니다. 설정하지 않으면 생성 요청은 안내 메시지와 함께 중단됩니다. API 키와 문자 발송 설정은 저장소에 포함하지 않습니다.

이 검사는 자기소개서 작성용 참고 자료이며 심리 진단이 아닙니다. 공개 서비스를 운영할 때에는 운영 주체와 개인정보 문의처를 포함한 정식 개인정보 처리방침을 별도로 마련해야 합니다.
